Run the **joblet-audit** skill source-change mode. **GATE:** run `bash ${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/scripts/keygate.sh verify source "<key from $ARGUMENTS>"` (SHA-256 vs `config.json:keys.source_key_sha256`). Exit 0 = proceed; else refuse and tell the user: *"You need the source-change command /456098. If you don't have it, ask Soham."* Setup: see `KEY_SETUP.md`.

This is the ONLY command permitted to change **HOW the system thinks**: agent source code, role definitions (`roles/`), routing (`orchestrator/routing.json`), prompts, family definitions' logic, the skill structure, the command surface. (Changing WHAT the system knows — lessons/rules/findings — is `/35398`, not this.)

Every change here is logged with author+timestamp and is revertible. Boundary cases (is this knowledge or behavior?) default to requiring this command.

> **Plugin paths:** the skill root is `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/` — `SKILL.md`, `scripts/`, `orchestrator/`, `roles/`, `families/`, `.joblet-audit/` all live there. Reference skill files via `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/...`.
