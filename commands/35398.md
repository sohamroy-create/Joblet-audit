Run the **joblet-audit** skill apply-updates mode. **GATE:** run `bash ${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/scripts/keygate.sh verify approver "<key from $ARGUMENTS>"` (compares SHA-256 to `config.json:keys.approver_key_sha256`). Exit 0 = proceed; anything else → refuse, no side effects. Setup: see `KEY_SETUP.md`.

Then: render the quarantine report; for each item the approver approves, promote it to the relevant `.joblet-audit/checklists/<family>.md` **only if its regression case flips FAIL→PASS**; write to the canonical corpus with author+timestamp+revertible changelog; archive rejected items with reason; flag conflicts (never silently overwrite).

**SCOPE GUARD (hard rule):** apply ONLY the proposed items in the report. If the operator tries to go beyond the proposed scope, OR — at your discretion — the change is a fundamental change to agent logic/behavior (HOW the system thinks, not WHAT it knows), HALT and require **/456098**. If they lack it: *"You need the source-change command /456098. If you don't have it, ask Soham."*

> **Plugin paths:** the skill root is `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/` — `SKILL.md`, `scripts/`, `orchestrator/`, `roles/`, `families/`, `.joblet-audit/` all live there. Reference skill files via `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/...`.
