Run the **joblet-audit** skill report mode. Read `.joblet-audit/quarantine.jsonl` and compile every quarantined proposal into a **Word .docx** (NOT markdown) named `joblet-audit-weekly-report-<date>.docx`.

Each row: proposed change · reason · the lesson/fix · trigger finding · conflicts-with · regression-case status (FAIL→PASS?).

Read-only: this command renders the queue for human review before `/35398`. It approves/changes nothing. No key required.

> **Plugin paths:** the skill root is `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/` — `SKILL.md`, `scripts/`, `orchestrator/`, `roles/`, `families/`, `.joblet-audit/` all live there. Reference skill files via `${CLAUDE_PLUGIN_ROOT}/skills/joblet-audit/...`.
