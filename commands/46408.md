---
description: Rotate the read-only Vercel/Supabase/GitHub tokens (Approver key required).
argument-hint: "<approver-key>"
---

Run the **joblet-audit** skill rotate-keys mode. **GATE:** run `bash scripts/keygate.sh verify approver "<key from $ARGUMENTS>"` (SHA-256 vs `config.json:keys.approver_key_sha256`). Exit 0 = proceed; else refuse. Setup: see `KEY_SETUP.md`.

Scope: the **read-only** Vercel/Supabase/GitHub provider tokens (least-privilege; never admin). Steps: check each token's `*_rotated_at`; if older than `rotation_interval_days` (15) → block until rotated. Guide/perform rotation in the provider, store the new token in the approver's LOCAL secret store (never in this repo), update `*_rotated_at`, invalidate old, log the event. Also run ad-hoc on employee departure.

Build-correctness note: durable enforcement is short token expiry set at creation in the provider; this command is the reminder/convenience + blocking layer.
